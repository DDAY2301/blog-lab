# bloglab-editorial-quality

Require title, credible source, factual date, clear Slovenian writing, relevant category, and an original summary with no unsupported claims. Reject stale 2019-style sports fixtures presented as new. Sport includes cycling/hiking/forests/outdoor activity, not culture or generic travel. Weekend is nightlife, gigs, DJs and venues when events are documented. No image generated by AI or photo selected solely by generic category when it implies a specific unrelated event. Respect CC BY/CC BY-SA/CC0 attribution requirements and do not assume all online photos are reusable. Label illustrative imagery honestly, store photographer/license/source and ensure no false association with the event.

## Operating procedure
1. Read `AGENTS.md`, current code and latest evidence before diagnosing.
2. Record objective, evidence and severity (S0–S3); prefer smallest change.
3. Use a feature branch and PR; never edit secrets or bypass review gates.
4. Verify the affected area with tests; mark unrun checks as NOT RUN.
5. Summarize results, risks and release decision without inventing successful deployment.
